NAME

DW::Auth - Alternate authentication styles.

SYNOPSIS

API

$class->authenticate( %opts )

Authentication methods ( specifiable by opts, in order of preference ):

All of the following can accept either 1 or a hashref of specific options.

    Acceptable options:

    allow_duplicate_nonce

    digest HTTP Digest

    remote Use the value of LJ::get_remote

Additional options:

_keep_remote Do not call LJ::set_remote with the authenticated user.
