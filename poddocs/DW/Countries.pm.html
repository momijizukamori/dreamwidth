NAME

DW::Countries - Replacement for LJ::load_codes( { country => ... } )

DESCRIPTION

This is at this point just a replacement for LJ::load_codes( { country => ... } ). It may become more in the future, eg by taking on subcountry (state/province/etc...) management as well.

SYNOPSIS

  DW::Countries->load( \%countries ) # %countries = ( AF => 'Afghanistan', ... )

API

DW::Countries->load( $hashref )

Sets %$hashref to a hash of alpha-2 uppercase country code => country name for all active country codes.

DW::Countries->load_legacy( $hashref )

Adds some additional legacy codes for displaying older data where appropriate.
