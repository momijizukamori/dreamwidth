NAME

DW::StatData::ActiveAccounts - Active accounts, by #days since last active

SYNOPSIS

  my $stats_obj = DW::StatData::ActiveAccounts->new( %$data );

  # Don't use in web context.
  my $data = DW::StatData::ActiveAccounts->collect( @keys ); # See list below

An account is counted as active when it logs in, when it posts an entry (when posting to a community, both the poster and the community are marked active), or when it posts or edits a comment.

API

$class->collect

Collects data for the following keys:

active_1d, active_1d-level name, active_1d-level name-type letter

Number of accounts active in the last 24 hours (total, for each account level, and for each account level and type - for personal, community, and identity accounts only)

active_7d, active_7d-level name, active_7d-level name-type letter

Number of accounts active in the last 168 (7*24) hours (total, for each account level, and for each account level and type - for personal, community, and identity accounts only)

active_30d, active_30d-level name, active_30d-level name-type letter

Number of accounts active in the last 720 (30*24) hours (total, for each account level, and for each account level and type - for personal, community, and identity accounts only)

In the above, level name is any of the account level names returned by DW::Pay::all_shortnames or "unknown", and type letter is P for personal, C for community, or I for identity (OpenID, etc).

BUGS

Because not all account types are collected separately, only P/C/I, but the per-level stats count all types, the numbers don't add up. This is arguably a bug in the design.
