NAME

DW::EmailPost::Base - Basic email posting behavior

SYNOPSIS

This is the basic email posting behavior. Subclasses should implement the following:

_find_destination - given a list of email addresses, return one you're interested in (or undef if none)
_parse_destination - given an auth string taken from the "to:" email header, set the user/journal/validated information
_process - process the email. ::Base does some of the common cleanup for you. It's up to you to finish the job. Call $self->cleanup_body_final in here

CLASS METHODS

$class->find_destination( $mime_entity )

Given a mime entity object, return the scalar $user journal (or undef) that this email is destined to post to

Subclasses must implement a _find_destination sub

$class->should_handle( $mime_entity )

Given a mime entity object, return 1 if we're interested in handling this. Return 0 if not.

INSTANCE METHODS

$self->process

Process the email. Returns a status message indicating either success or reason for failure

This base implementation pulls out subject/body, finds the important metadata from the email (such as address, username, etc) and does character decoding.

Subclasses must implement a _process sub for subclass-specific handling

$self->parse_destination( $auth_string )

Given an auth string (lefthand side of "to:" header), set authorization options

Must set: u, journal

Subclasses must implement a _parse_destination sub

$self->cleanup_body_final

Final cleanup of the body text: remove signatures, adjust whitespace, etc. Subclass should call this when doing _process

$self->set_error_address

Given a user object and an email address, discover the appropriate email to send any error messages to.

Fallback to raw address if no explicit allowed senders.
