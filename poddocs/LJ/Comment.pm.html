NAME

LJ::Comment

CLASS METHODS

INSTANCE METHODS

$self->threadroot_url URL to the thread root. It would be unnecessarily expensive to look up the thread root, since it is only rarely needed. So we set up a redirect then look up the thread root only if the user clicks the link.

$self->threadrootid Gets the id of the topmost comment in the thread this comment is part of. If you just want to create a link, do not call this directly. Instead, use $self->threadroot_url.

$cmt->userpic

Returns a LJ::Userpic object for the poster of the comment, or undef.

If called in a list context, returns ( LJ::Userpic object, keyword )

$cmt->userpic_kw

Returns the userpic keyword used on this comment, or undef.

$cmt->admin_post

Returns true if this comment is an official administrator comment.
