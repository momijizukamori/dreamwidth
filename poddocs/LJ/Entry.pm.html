$entry->admin_post

$entry->userpic

Returns a LJ::Userpic object for this post, or undef.

If called in a list context, returns ( LJ::Userpic object, keyword )

See userpic_kw.

$entry->userpic_kw

Returns the keyword to use for the entry.
